# ЦМК АВРОРА — новый интерфейс «Пульт» (03.09.2026)

Единый бриф для всех, кто строит экраны. Победитель панели концепций — «Пульт»
(бенто-доска без бокового меню и шапки, док внизу), с прививками из «Линии»
(конвейер завода как домашний экран), «Прибора» (мачта как прибор) и «Разворота»
(журнальная типографика, лист-деталь как правая страница).

Вердикт владельца о прежнем интерфейсе: «как просто база данных», «остался тот же
формат», «не гармонично», «хочу, чтобы я не узнал свой сервис». Поэтому исчезают
все три опорных признака админки: боковое меню 260 px, шапка 64 px, таблица во весь
экран. Mantine `AppShell`, `Card`, `Table` из оболочки уходят; Mantine остаётся для
полей ввода, Select, DatePicker, Modal/Drawer, Tooltip, Notifications.

## 1. Жёсткие правила (нарушать нельзя)

1. Страница НИКОГДА не прокручивается. `html, body { overflow: hidden }`. Раздел целиком
   влезает в 1440×900 и 1280×800. Данных больше экрана → срезы, страницы, клавиши.
2. Экран начинается с ответа: первая плитка — «что требует решения». Список вторичен.
3. Палитра ровно: холст `#F0F0ED`, поверхности `#FFFFFF`, чернила `#000000`, голубой
   `#82ADD4` (одна большая плоская панель на экран), жёлтый `#DDFD2C` (маркер ≤ 2 %
   площади: черта активного раздела, пилюли-счётчики, текущий столбик, последняя точка
   спарклайна, фокус-кольцо; никогда не плитка, никогда не текст). Состояния: готово
   `#5F8C5A`, просрочено `#D6452F` — только текст/точка/полоса, никаких заливок.
   Токены уже есть: `--ref-*`, `--c-*` в `src/index.css` и `src/styles/aurora.css`.
4. Текст ≥ 13 px. Числа лёгкие (вес 300), `font-variant-numeric: tabular-nums`.
5. Шрифт Onest (вариативный 100–900). Коды заказов/артикулов — JetBrains Mono.
6. Движение под `prefers-reduced-motion` и `useMotionOff()`. В скрытой вкладке
   framer-motion не анимирует — ничего не должно застревать на opacity 0.
7. Никаких чужих цветов Mantine (`teal`, `blue`, `orange`, `red`…): только
   `brand` / `accent` / `success` / `warning` / `danger` / `gray` / `ink`.

## 2. Оболочка

### Док (единственная навигация)
Плавающая капсула внизу по центру: 12 px от нижнего края, высота 56 px, скругление
28 px, белое стекло `rgba(255,255,255,.88)` + `backdrop-filter: blur(20px)`, обводка
1 px `rgba(0,0,0,.06)`, тень `0 8px 32px rgba(0,0,0,.10)`. Иконки 40 px в ячейке 48 px,
10 разделов + волосяной разделитель + Настройки. Магнификация под курсором 40→60 px
(соседи 52/46, радиус 120 px, кубическое затухание), капсула растёт до 72 px в зоне
курсора. Подпись раздела — чёрная пилюля 13/500 над иконкой (задержка 80 мс). Активный
раздел — жёлтая черта 20×4 px под иконкой, едет между иконками через `layoutId`.
Счётчики: жёлтая пилюля 18 px с чёрной цифрой (Заказы — просроченных), красная точка
6 px (Материалы — дефицит, Деньги — долг > 30 дн). Клавиши ⌘1…⌘9, ⌘0; ⌘, — Настройки.
Док один на все разделы, не прячется. Роль сокращает состав дока (кладовщик 6, мастер 4).
На touch/планшете: без магнификации, полоса 64 px с подписями под иконками.

### Верхняя полоса
44 px, прозрачная (холст просвечивает), без границы. Слева 24 px: `Mast` 28 px как
прибор (огонь = худшее состояние завода: красный при просрочке, жёлтый при
«внимание»; волны сигнала — пока идёт запрос) + название раздела 18/500 + контекст
13/400 серым («чт, 3 сен» / «1–14 из 27»). Центр: живые числа завода — пары «число
18/300 + подпись 13/400» (в работе · ч в очереди · просрочено · без норм), кликабельны,
просроченное — красные чернила. Справа: поле ⌘K 220×32 (белое, скругление 16) и чип
пользователя 32 px (инициалы на голубом, имя 13/500, роль 13/400).

### Палитра ⌘K (cmdk)
640×420 по центру, белая, скругление 20; фон затемняется чёрным 24 %, доска
`scale(.98)` + `blur(2px)`. Ищет заказы, объекты, изделия, материалы, контрагентов и
команды («Открыть заказ», «Перейти в Цех», «Изготовлено»). Пустое состояние — `Mast`
64 px с сигналом и подсказки клавиш. Заменяет `GlobalSearch`.

### Геометрия
1440×900: полоса 44 + зазор 12 → доска с y=56; снизу резерв 80 px под док; доска
1392×764. 1280×800: поля 20 px, доска 1240×664. `html { overflow: hidden }`,
`overscroll-behavior: none`.

## 3. Доска раздела (Board)

CSS grid 12 колонок × 6 рядов (1280: 5 рядов), gap 12 px, `overflow: hidden`.
1440: колонка 105 px, ряд 117 px. 1280: колонка 92 px, ряд 123 px. Размеры плиток
приходят из `useBoardMetrics()` (ResizeObserver), не из медиазапросов.

Плитки — белые, скругление 20, без обводок, padding 20, тень только на ховере
(`--ref-sh-hover`). На доске ровно ОДНА голубая плитка (`#82ADD4`, чёрный текст) и не
больше одной чёрной (`#000000`, белый текст — «Сейчас», задачи с клавишами).
Тонкая цветная полоса-акцент слева 3 px (голубая/жёлтая/красная/зелёная) — единственный
носитель состояния плитки.

### Типы плиток
1. **Hero «Ответ»** 4×3 — кикер 13/500 капителью серым («ПРОСРОЧЕНО»); число-герой
   96/300 (1280: 80/300) с единицей 20/400 серым по базовой линии; фраза-следствие
   15/400, ключевое словосочетание закрашено жёлтым маркером («на 41,6 млн ₸»);
   волосяная линия; 3 виновника строками 44 px (имя 15/500, подпись 13 серым, число
   15/300, полоса доли 3 px чёрная); «ещё 20 →» 13/500; чёрная пилюля-действие 36 px.
   Первая плитка каждого раздела. Обычно она и есть голубая.
2. **Digit** 2×1 — заголовок 13/500, число 40/300 (1280: 34), подпись 13/400,
   опционально спарклайн 72×24 (stroke 1.5 чернила 40 %, последняя точка жёлтая 6 px).
   Клик = срез списка.
3. **Trend** 4×2 / 6×2 — столбики недель (чернила 12 %, текущая — жёлтая), число-итог
   40/300. Дуга «Dial» из «Прибора» — вариант Trend для долей (маржа, готовность):
   кольцо 120 px, обвод 6, дорожка холст, дуга чернила, засечка нормы жёлтая.
4. **Ledger** 6×3 / 8×3 / 12×3 — шапка 40 px: срезы-пилюли (активная чёрная; счётчики
   жёлтыми пилюлями 18 px) + «1–14 из 27 ‹ ›»; строки 36 px 13–15 px `tnum`, число
   строк — `useFitRows` от фактической высоты; разделители 1 px `rgba(0,0,0,.05)`;
   стрелка «⟶» на ховере строки; полоска-прогресс 2 px жёлтая под шапкой = доля
   пройденных страниц. Клавиши ← → / J K — страницы, 1…5 — срезы, F или «⤢» —
   разворот в 12×6 (View Transition 280 мс; Esc — назад). Разворот = старая таблица,
   вторичная и за кликом.
5. **Now** 4×2 чёрная — нумерованный список 3–5 задач 15/400 белым, белая пилюля
   «Открыть →», клавиша справа в жёлтой мини-пилюле.
6. **Site** 2×2 — `Mast` 72 px с progress = доля изготовленного, число 40/300 «5/7»,
   название площадки 14/500.
7. **Rail** (только домашний экран) — конвейер завода: Заказ → Изделия → Материалы →
   Цех → Склад ГП → Отгрузка → Деньги; узлы Ø 96 с числом 36/300 и подписью, линия
   рисуется `stroke-dashoffset`, ответвления Прайс ▲, Закупки ▼, Подряд ▼. Клик по узлу
   — переход в раздел (морфинг узла в заголовок).

Правило крупно/мелко: одно число 96, не более шести чисел 40, остальное 13–15.
Герой — то, за что завод платит деньгами (просрочка, дефицит, долг).

### Деталь без ухода — Sheet
Панель 560 px справа (1280: 480), белая, скругление 20 слева, отступ 12 px от края и
верха, высота = доска (док остаётся виден). Строка `view-transition-name: order-{id}`
перетекает в шапку листа (280 мс, `cubic-bezier(.2,.8,.2,1)`); доска `scale(.97)` +
`blur(2px)` + затемнение 12 %. В листе: номер 28/500 + статус, три числа 40/300,
вкладки-пилюли, тело со своим `useFitRows`, ↑↓ — соседняя строка без закрытия, Esc —
закрыть. Без View Transitions (Safari < 18) — `layoutId` + `AnimatePresence`.
Существующая `OrderCardProvider`/`OrderDetail` переезжает внутрь Sheet.

## 5. Типографика

Onest везде; `font-feature-settings: 'tnum'` на числах; `letter-spacing −0.01em` при
≥ 28 px, −0.02em при ≥ 64 px.
- Название раздела в полосе: 18/500, lh 1.
- Число-герой: 96/300, lh .92 (1280: 80). Единица: 20/400 серым по базовой линии.
- Живые числа полосы: 18/300 + подпись 13/400.
- Число плитки Digit/Dial/Ledger: 40/300 (1280: 34).
- Число узла Rail: 36/300.
- Кикер/заголовок плитки: 13/500, `rgba(0,0,0,.55)`, капитель с трекингом .06em.
- Строка списка: 14/400 основное, 13/400 серым второстепенное; числа 14/300 `tnum`.
- Фраза-следствие: 15/400. Пилюли: 13/500.

## 6. Движение

Пружины: основная `SPRING {420, 34, .9}`; «тяжёлая» для дока и листа `{380, 30, 1}`;
«быстрая» для пилюль `{600, 40, .6}`. Только `transform`/`opacity`; `will-change`
только на время анимации.

Первая загрузка (≤ 900 мс): 0 мс — холст и полоса `opacity 0→1` 120 мс, мачта в
полосе строится 400 мс, огонь на 400-й; 80 мс — док выезжает `y +32→0` тяжёлой
пружиной, иконки стаггер 20 мс (`scale .6→1`); 160 мс — плитки стаггер 40 мс в порядке
чтения (`y 14→0`, `scale .98→1`); внутри плитки до данных — `MastLoader` 48 px; данные
пришли — мачта растворяется 120 мс, число считается 600 мс (`@number-flow/react`),
спарклайны рисуются `stroke-dashoffset` 500 мс, столбики растут 400 мс стаггер 30 мс,
герой — 800 мс последним. Повторный вход в сеансе — 40 % длительностей.

Ховер плитки: `translateY(−3px)` + тень + 3D-тилт до 3° (только Digit/Hero/Site, один
`pointermove` на доске через rAF; на touch и reduced-motion — выкл.). Переход раздела:
View Transitions — старая доска `opacity→0, y −6` 180 мс, новая `y +10→0` 340 мс;
полоса и док не дёргаются (`view-transition-name: app-chrome`). Обновление данных:
изменившаяся ячейка — вспышка жёлтым `background` 0→.35→0 за 600 мс. Мутация
(«Изготовлено»): строка сжимается по высоте пружиной, счётчики докручиваются, на мачте
в полосе пробегают волны сигнала. Курсор: отблеск `--mx/--my` на плитке под курсором
(уже есть). Пустое состояние — `Mast` строится, подпись «Всё изготовлено».

## 10. Риски и снятие

- 11 иконок без подписей — подпись-пилюля на ховере, цифры при удержании ⌘, роль
  сокращает док, на планшете подписи всегда.
- 1280×800 давит числа — Board переключает 6→5 рядов, Digit 40→34, Hero 96→80, Ledger
  теряет строку; всё через `useBoardMetrics`/`useFitRows`, не через медиазапросы.
- Тилт и магнификация на слабых ноутбуках — один rAF-слушатель, transform only,
  `navigator.hardwareConcurrency ≤ 4` → режим без тилта.
- Safari < 18 без View Transitions — `layoutId` + `AnimatePresence` с тем же таймингом.
- «Данных стало меньше» — срезы показывают полный объём («Все 694»), F даёт полную
  таблицу за одну клавишу, ← → без мыши.
- Mantine-остатки вернут старый вид — `AppShell`/`Card`/`Table` из оболочки удалить в
  первом коммите, стили `.mantine-Card`/`.mantine-AppShell` из `aurora.css` вычистить.
